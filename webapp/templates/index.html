About PhytoGuard AI

An end-to-end deep learning project for precision agriculture

🎯

Project Overview

PhytoGuard AI is a computer vision system designed to assist farmers and agronomists in identifying plant diseases early and accurately. The system classifies leaf images into 11 categories covering diseases and healthy states across Apple, Corn (Maize), and Potato crops.

The project demonstrates the superiority of Vision Transformers over traditional CNN architectures for fine-grained image classification tasks, achieving near-perfect accuracy on the PlantVillage dataset.

⚙️

Technology Stack

  • PyTorch 2.9.1 Deep learning framework
  • 🤗 Transformers 4.57.1 ViT model library
  • Flask Web backend
  • Pillow / OpenCV Image processing
  • Apple MPS Metal GPU acceleration
  • Chart.js Visualization
🧠

Model Architecture

The backbone is ViT-Base/16 (Vision Transformer) pre-trained on ImageNet-21k and fine-tuned on PlantVillage. The model divides 224×224 images into 16×16 pixel patches, encodes positional embeddings, and applies 12 transformer encoder layers with multi-head self-attention.

Training Pipeline

  • 1
    Data Preparation — PlantVillage dataset (87K+ images), filtered to 11 classes with offline augmentation
  • 2
    Preprocessing — Resize to 224×224, normalize with mean/std=0.5 using ViTImageProcessor
  • 3
    Fine-tuning — HuggingFace Trainer API, 10 epochs, Apple M4 MPS acceleration
  • 4
    Evaluation — 5,198 validation images, per-class F1 scores, confusion matrix analysis
  • 5
    Deployment — Saved as safetensors, served via Flask REST API
